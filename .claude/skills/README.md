# Vendored skills

Design/UI skills vendored from upstream repos for use in this project.

- `ui-ux-pro-max/` — from https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT). Searchable UI/UX design database (styles, palettes, typography, UX rules) via `scripts/search.py`.
- `impeccable/` — from https://github.com/pbakaus/impeccable (Apache-2.0). Design review/refinement commands (`/impeccable audit|polish|critique|...`) via `scripts/context.mjs`.

Each folder's `LICENSE.upstream` is the original repo's license, preserved for attribution.

Not vendored: the "theme-factory" skill from claudeskills.org — that domain is blocked by this environment's network policy.
